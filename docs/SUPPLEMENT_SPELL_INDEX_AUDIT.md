# Supplemental Official Spell Index — Milestone 17.6

**Status:** Curated reference-only index. This is **not** a complete catalogue of every D&D 5e spell, nor an import of the four books' rules text.

## Counting and content distinctions

- 339 full-description SRD 5.2 spell entries remain unchanged. Their detailed at-the-table guidance was added in Milestone 16.1.
- 52 PHB 2024 reference-only names remain unchanged; 17 alternate-naming search aliases are not counted separately.
- **39 additional reference-only spell names** from four official supplemental books bring the indexed total to **430 distinct entries** (before private user imports).
- Each new record contains an identifying name, spell level, source label, limited school/class indexing, and optional eligibility note. Casting mechanics (action type, range, components, concentration, ritual, effects, upcasting) are deliberately **not inferred**.
- A reference can be selected as a spell and a spell slot can be marked used. Folio does **not** apply its effects, resolve concentration, or claim it has verified current rules.

## Official catalogues checked

- Strixhaven: D&D Beyond's published five-spell table, with level, school, and class lists: https://www.dndbeyond.com/sources/dnd/sacoc ; table also visible in https://www.dndbeyond.com/forums/dungeons-dragons-discussion/play-by-post/127530-strixhaven-adventure.
- Wildemount: D&D Beyond's 15-spell support summary and Dunamancy overview, including subclass restrictions: https://www.dndbeyond.com/forums/d-d-beyond-general/release-issues-support/59558-support-thread-explorers-guide-to-wildemount ; https://www.dndbeyond.com/posts/757-spell-spotlight-dunamancy . Individual spell levels were cross-checked against published level lists.
- Tasha's: Official Tasha's launch-support spell lists: https://www.dndbeyond.com/forums/d-d-beyond-general/release-issues-support/87774-tashas-cauldron-of-everything-issues-and-support?page=33 ; original Tasha's summoning-spell summary: https://www.dndbeyond.com/posts/924-spell-spotlight-new-summoning-spells-from-tashas . Only names absent from the earlier 2024 PHB/SRD index were added.
- Fizban's: Official dragon-magic source overview: https://www.dndbeyond.com/sources/dnd/ftod ; official Fizban support thread: https://www.dndbeyond.com/forums/d-d-beyond-general/release-issues-support/123752-fizbans-treasury-of-dragons-issues-and-support .

**Edition caution:** These four supplements predate the 2024 revised PHB. Their original class lists and spell levels are indexed as historical publication metadata, not a promise that every item is 2024-compatible or has not since been revised. Where an SRD/PHB replacement exists, the newer entry is preferred and is not duplicated here. Complete official errata and replacement checking remains open.

**Wildemount caution:** Dunamancy access normally belongs to Chronurgy and Graviturgy Wizards. The author publicly noted ambiguity over strict subgroup restrictions; this app uses the narrower subgroup interpretation in its automatic picker. The table can grant exceptions manually. Both wizard traditions still need fuller M18 subclass implementation; a basic Wizard will not automatically receive these spells.

## Outstanding follow-up work

1. Cross-check individual historic class access/levels against new releases and published errata before treating every 2014-era reference as current-rule legal.
2. Continue indexing remaining official supplements (including Xanathar's, Acquisitions Incorporated, setting books, recent 2025–26 releases). Do not mark a sourcebook as fully bundled because some references appear.
3. Add full mechanics only when valid license, user-provided personal content or appropriate right to include them exists; this ZIP contains no scans or commercial spell descriptions.
4. Support class-specific optional spell-list features, expanded Artificer and Wildemount subclasses in M18.
5. Test physical Windows `file://` storage and a real export/import cycle on the owner's machine.
