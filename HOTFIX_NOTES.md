# Milestone 15.2 — Artwork Removal Hotfix

What changed:
- **Remove portrait** immediately saves the removal to the character library.
- **Restore book emblem** immediately saves the restored default emblem.
- The status message confirms when a removal is saved. Wait for that confirmation before closing the app.
- All other artwork edits still require **Save artwork**.

Before updating, export a JSON backup from your current Folio.

**Full install:** Extract the complete ZIP into a new folder and launch `Open The Folio.cmd`.

**Update-only:** Open the extracted patch and copy the contents of its `the-folio` folder into the existing **Milestone 15.1** project folder, replacing matching files while preserving the directory structure. Then reopen the Folio. Do not copy the folder inside itself.

No GitHub update required.
