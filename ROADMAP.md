# Roadmap

The following describes planned work, not features that are already complete. Scope and priorities may change based on tabletop testing.

| Phase | Focus | Status |
| --- | --- | --- |
| Milestones 1–7 | Pip-specific sheet, spells, combat, inventory, journal, printing | Implemented |
| Milestones 8–9 | Multi-character library, campaign folders, starter builder, reusable homebrew | Implemented with documented limitations |
| Milestone 10 | Expanded SRD spells and weapons, Quick Roll | Implemented with documented limitations |
| Milestone 11 | Character themes, custom backgrounds and dice colors | Implemented |
| Milestone 12 | Offline 3D dice animation, Windows launcher and release hardening | Current alpha |
| Planned | Save/recovery verification on real Windows systems | Not yet fully verified |
| Planned | Complete class/subclass progression and accurate level-up decisions | Not yet implemented |
| Planned | Multiclassing and combined spellcaster resources | Not yet implemented |
| Planned | Further weapon mastery and active-effect automation | Not yet implemented |
| Exploratory | Collision-driven physics dice | Not yet implemented |
| Exploratory | Optional native Windows wrapper | Not yet implemented |

## Core product principles

- Familiar D&D sheet structure first; thematic styling should not obscure rolls, HP, or features.
- Keep character data private, offline-first, and exportable.
- Preserve Pip's specialized behavior without imposing it on new characters.
- Do not automate unverified rules silently; make manual/house-rule overrides visible.

For detailed current limitations, see [README.md](README.md) and [TESTING.md](TESTING.md).
