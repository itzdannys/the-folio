# Equipment metadata attribution — Milestone 17.4

This project incorporates facts and transformed metadata from the **System Reference Document 5.2.1** (SRD 5.2.1) by Wizards of the Coast LLC, https://www.dndbeyond.com/srd, licensed under **Creative Commons Attribution 4.0 International**: https://creativecommons.org/licenses/by/4.0/legalcode.

The original source for equipment specifications, armor properties, tool options, prices and weights is the official **Equipment** section: https://www.dndbeyond.com/sources/dnd/br-2024/equipment (and SRD 5.2.1). The source tables have been restructured as JavaScript fields in `js/equipment-catalog.js`. Short explanatory summaries, categorization, and cautions have been written for Folio's interface, not copied as complete rulebook descriptions. `js/weapon-catalog.js` remains separately attributed in `WEAPON_DATA_LICENSE.md`.

Folio is independent of Wizards of the Coast. Full descriptions from commercial sourcebooks are not included, and the source manager does not grant access to books the user does not possess.
